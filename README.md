# La Frames India

La Frames India is a refined, responsive travel showcase website that highlights some of the most iconic destinations in India. The project presents a modern, elegant browsing experience with a curated collection of tourist places, travel details, and a clean contact section.

## Overview

This project is designed to provide a polished introduction to India’s cultural and natural landmarks through a visually appealing one-page experience. It combines simple web technologies with a strong emphasis on layout, storytelling, and user experience.

## Features

- Responsive single-page layout for desktop and mobile devices
- Elegant hero section with a premium visual style
- Destination-based gallery for exploring featured places
- Travel highlight cards with descriptions and airport distance details
- Interactive contact cards that reveal information on click
- Clean and modern styling with custom typography and soft, warm colors

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Launch the website by opening [index.html](index.html) in your browser.

If you are using Visual Studio Code, you can also preview it with the Live Server extension for a smoother local development experience.

## Usage

- Browse the home section to explore the theme of the site.
- Use the destination buttons to switch between featured Indian locations.
- Click the contact cards to reveal email, phone, and location details.

## Purpose

La Frames India is ideal for showcasing travel inspiration, destination highlights, and a modern front-end design in a lightweight static website format.
